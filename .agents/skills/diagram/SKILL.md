# Blog diagram

저장소 AGENTS.md, docs/index.md, docs/static-diagrams.md와 catalog를 먼저 읽고 현재 branch, HEAD, 사용자 변경을 확인한다. 이 스킬은 도식 작성과 검증을 지원한다. 원격 게시, 머지와 운영 배포는 현재 사용자의 승인 범위를 따른다.

이 블로그의 캔버스, 표시, export와 의미 보존 기준은 저장소 AGENTS.md와 docs/static-diagrams.md를 정본으로 삼는다. 전역 generic inline SVG 지침도 준수하며, 블로그별 1920 x 1080 고정 표시와 반응형 금지 기준을 적용한다.

## 고정 FHD 작성

모든 그림을 1920 x 1080, 16:9의 고정 캔버스에서 설계한다. SVG의 width="1920", height="1080", viewBox="0 0 1920 1080"을 사용하고 PNG의 실제 치수도 정확히 1920 x 1080이어야 한다.

박스, 화살표와 라벨의 좌표를 inline SVG에 직접 쓴다. Mermaid 등 자동 그래프 레이아웃으로 대체하지 않는다. 기존 이미지의 확대, 축소, crop이나 비율 왜곡으로 캔버스를 맞추지 않는다. 글자 크기, 카드 폭, 여백과 분기 배치를 원래 의미에 맞게 설계한다.

HTML figure의 기존 의미 구조와 접근성 이름을 보존한다. source와 SVG의 노드, 순서, 방향, 분기 조건, 합류와 반복을 각각 대조한다. 비교의 병렬 대상 사이에 실행 순서를 새로 만들지 않는다. 역할이 같은 요소는 같은 색과 선을 사용하고 배경은 흰색으로 고정한다. 원본 spec, Draw.io, raster, 라이선스와 rollback 자료는 보존한다.

## 표시와 접근

데스크톱과 모바일에서 SVG와 PNG의 표시 크기를 1920 x 1080으로 고정한다. 화면 폭에 따른 자동 축소, responsive 재배치, container query, breakpoint 변형은 금지한다. SVG 내부 배치, 순서와 연결은 모든 화면에서 동일하다.

좁은 화면에서는 스크롤 가능한 영역과 키보드 접근을 제공한다. 별도 HTML viewer의 기본 그림 크기도 1920 x 1080으로 고정한다. 사용자가 직접 선택하는 100%, 125%, 150% 확대만 허용하고 확대된 전체 크기만큼 스크롤 영역을 확보한다. raw PNG 링크의 브라우저 기본 자동 축소를 고정 크기 검증 증거로 쓰지 않는다. 그림을 컨테이너에서 잘라 숨기지 않는다. width:100%, max-width:100%, height:auto 등 그림을 자동 축소하는 규칙을 적용하지 않는다.

## 검증

정적 검증과 실제 렌더링은 별도로 기록한다. 모든 SVG/PNG의 치수와 viewBox를 검사하고 source 대응, 글꼴과 라이선스, 텍스트 경계, 겹침, 잘림, 방향과 화살촉을 확인한다. 각 source의 구조 검증, SVG 작성, PNG 생성, 실제 시각 검토와 게시 완료 수를 나눠 보고한다.

브라우저 자동화는 현재 전역 지침의 Aside 단일 경로만 사용한다. Aside MCP가 없으면 문서화된 one-shot CLI 예외만 사용한다. 허용된 경로가 없거나 캡처가 실패하면 렌더링과 PNG 검증을 미완료로 남긴다. 기존 Playwright/Chromium exporter를 정책 우회로 실행하거나 다른 브라우저를 설치하지 않는다.

실제 desktop과 360px/390px 화면에서 표시 크기가 항상 1920 x 1080인지 확인한다. 좁은 화면의 가로 스크롤이 모든 요소에 도달하며 글자 크기, 순서와 연결이 변하지 않는지 검증한다. 실제 PNG를 열어 가독성과 잘림을 판정한다. 정적 parser 통과만으로 시각 품질 통과를 주장하지 않는다.

무거운 build와 전체 corpus export는 공유 자원 담당자와 직렬 조율한다. 사용자의 첫 시안 승인은 현재 요청에 확인됐으면 다시 요구하지 않는다. 머지와 운영 배포는 별도 승인 범위를 확인한다.
