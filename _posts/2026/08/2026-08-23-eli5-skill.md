`eli5`는 모르는 주제를 큰 그림과 적은 단어로 설명하는 HTML 아티팩트를 만들어주는 Claude Code 스킬입니다. Anthropic이 운영하는 커뮤니티 마켓플레이스에 올라와 있습니다. 이름은 "Explain Like I'm 5"에서 왔습니다.

---

## 1. 설치

```bash
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install eli5@claude-community
```

Claude Code 세션 안이라면 `claude plugin` 대신 `/plugin` 슬래시 명령을 씁니다.

설치 확인은 `claude plugin list`입니다.

```text
  eli5@claude-community
    Version: 1.0.0
    Scope: user
    Status: enabled
```

새 세션부터 스킬이 로드됩니다. 설치한 세션에서는 아직 잡히지 않습니다.

---

## 2. 사용법

`/eli5` 뒤에 설명받고 싶은 주제를 적습니다.

```text
/eli5 how does DNS work
/eli5 Discord 봇은 어떻게 동작하나요
```

결과는 채팅 답변이 아니라 HTML 아티팩트입니다. 큰 도형과 짧은 라벨로 단계별 다이어그램이 나오고, 문장은 최소한으로 붙습니다.

---

## 3. 스킬 구성

설치된 실체는 아래 경로에 놓입니다.

```bash
~/.claude/plugins/cache/claude-community/eli5/1.0.0/
```

들어 있는 파일은 `plugin.json`, `README.md`, `skills/eli5/SKILL.md` 세 개입니다. MCP 서버도 없고 스크립트도 없습니다.

`SKILL.md` 본문은 아래 세 줄이 전부입니다.

```markdown
Explain like I'm someone who knows nothing about this topic,
using a HTML artifact with big pictures and few words.

Topic: $ARGUMENTS
```

frontmatter의 `name`과 `description`을 합쳐도 열 줄이 안 됩니다.

이 스킬이 고정하는 것은 모델의 능력이 아니라 **출력 형식과 청자 수준** 두 가지입니다. 같은 질문을 그냥 던지면 답변은 문단과 불릿으로 나오고, 설명 수준은 질문한 사람이 그 분야를 이미 안다고 가정한 쪽으로 기울기 쉽습니다. `eli5`는 "아무것도 모르는 사람"과 "HTML 그림"을 매번 강제해서 그 기울기를 없앱니다.

---

## 4. 언제 쓰고 언제 안 쓰나

- 처음 보는 프로토콜이나 서비스의 큰 흐름을 잡을 때 쓴다
- 남에게 설명할 자료의 초안이 필요할 때 쓴다
- 이미 아는 주제에는 쓰지 않는다. 아는 내용을 크게 그려주기만 한다
- 정확성 검증 장치가 없다. 산출물은 근거가 붙은 문서가 아니라 설명용 그림이다

마지막 항목은 짚어둘 만합니다. 그림은 설득력 있게 나오는데 그 안의 내용이 맞는지는 아무도 확인하지 않습니다. 큰 그림을 잡는 용도까지가 안전한 범위이고, 그 그림을 근거로 판단하려면 원문 확인이 따로 필요합니다.
